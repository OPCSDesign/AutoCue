Nextcloud

Keep your library in an AutoCue folder in Nextcloud — one folder per ceremony, one .md file per piece, “01 - ” prefixes set the running order. Every device reads the same library; this app keeps an offline copy for the lodge.

Use a dedicated app password (Nextcloud → Settings → Security). One-off server setup for browser access (CORS) is described in NEXTCLOUD.md in the AutoCue repository.
